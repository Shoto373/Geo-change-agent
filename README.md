# 🌍 Geo-Change-Agent: Поисковик и аудитор изменений на Земле

Платформа мониторинга изменений земной поверхности и аудита обезлесения (EUDR Compliance) на основе открытых данных дистанционного зондирования Земли (Sentinel-2 L2A / Landsat) с высокопроизводительным шлюзом на **Go**, геовычислительным ядром на **Python** и интерактивным веб-интерфейсом.

## 🚀 Быстрый старт

### Вариант 1. Запуск в один клик (Windows)
Просто запустите файл `run_dev.bat` или `run_dev.ps1` в корне проекта.
Скрипт автоматически запустит оба сервиса и откроет браузер по адресу:
👉 `http://localhost:8080`

### Вариант 2. Ручной запуск компонентов

#### 1. Запуск Python ML Engine
```bash
cd ml-service
python -m venv .venv
# Активация окружения:
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python server.py
```
*(Сервис поднимется на порту `http://127.0.0.1:8000`)*

#### 2. Запуск Go API Gateway
```bash
cd backend-go
go run main.go
```
*(Шлюз и веб-интерфейс поднимутся на порту `http://localhost:8080`)*

## 🎯 Соответствие стандарту EUDR (Regulation EU 2023/1115)
Система проводит проверку легальности цепочек поставок древесины, кофе, какао, сои и пальмового масла:
* **Дата отсечения (Cutoff Date):** 31 декабря 2020 года.
* **Порог обезлесения (Deforestation Threshold):** $\ge 0.5$ га сомкнутого полога леса.
* **Аудиторский отчет:** Автоматический расчет динамики NDVI, площади вырубки и уровня уверенности.
